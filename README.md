# AH13 Store — حزمة رفع مسطحة

كل الملفات في مستوى واحد. فك الضغط وارفع كل الملفات مباشرة في جذر مستودع AH13-Store. لا يلزم رفع مجلدات.

1. احتفظ بنسخة من المستودع القديم: Code > Download ZIP.
2. ارفع ملفات هذه الحزمة عبر Add file > Upload files ثم Commit changes. الملفات المطابقة تُستبدل؛ المجلدات القديمة لم تعد مستخدمة ولا يلزم حذفها لعمل النسخة الجديدة.
3. في wrangler.json غيّر database_id من الأصفار إلى UUID قاعدة ah13-store-db الموجودة. احتفظ باسم Worker الصحيح في name (المرفق ah13-store).
4. Cloudflare Build command: npm run build. Deploy command: npx wrangler deploy.
5. أضف أسرار التشغيل SESSION_SECRET وBOOTSTRAP_TOKEN كنوع Secret في إعدادات Worker خارج إعدادات Builds، بقيم عشوائية مختلفة لا تقل عن 32 حرفًا. لا ترفعها على GitHub. القيم المتكررة المكشوفة في الصور السابقة غير مناسبة.
6. النشر وحده لا يهيئ D1. يلزم فحص مخطط جداولك الحالية أولًا. npm run db:remote يأخذ نسخة احتياطية ثم يفحص توافق الأعمدة ويوقف العمل عند اختلافها دون حذف بيانات. يلزم npm ci وnpx wrangler login محليًا قبل تشغيله. لا تنفذ schema.sql يدويًا على قاعدة قائمة مجهولة المخطط.
7. بعد نجاح النشر وتهيئة القاعدة افتح رابط المتجر مع /#setup لإنشاء أول أدمن، ثم احذف BOOTSTRAP_TOKEN من أسرار Worker. لا تحذف SESSION_SECRET.

الأوامر المحلية: npm ci ثم npm test ثم npm run build.
للتطوير: npm run db:local ثم node local-secrets.mjs ثم npm run dev.

worker.js هو مدخل الخادم بدل src/worker.js. build.mjs ينسخ ملفات الواجهة الثمانية فقط إلى .assets. لا تغيّر assets.directory إلى جذر المشروع حتى لا تنكشف ملفات الخادم.

الواجهة عربي/إنجليزي، داكن/فاتح، PWA، مستخدم/مطور، طلب تطبيق وتحديث رابط، مكتبة، تقييمات وبلاغات ولوحة أدمن. R2 اختياري: أضف r2_buckets مع binding ICONS واسم bucket الفعلي لتفعيل رفع الصور. رابط HTTPS للأيقونة يعمل دون R2.

تنزيلاتي مكتبة مواقع محفوظة وليست تنزيل APK. iframe اختياري وبعض المواقع تمنعه؛ رابط الفتح الخارجي متاح دائمًا. الشعار بديل نصي؛ الشعار الأصلي لم يكن متاحًا.
لم يتم فحص مخطط قاعدة الإنتاج أو نشر هذه الحزمة على حسابك.
